Instructor Screen (prototype)

Pick which radar position to link with. Final Control is always linked automatically.
The Instructor screen does not run a simulation. Start Marshal / Approach / Final in their own tabs (each has its own ▶ START button); this screen connects automatically and lets you command their aircraft.
Click an aircraft (scope or list) → Text (or press T / Enter) to type an instruction. On final: Climb / Descend (or PgUp / PgDn) for a silent glidepath offset. Arrow keys move the selected data block. Mouse wheel zooms. Next aircraft check-in: Auto (timed) or Manual, then N checks the next one in. Instructor actions never get a pilot readback.
